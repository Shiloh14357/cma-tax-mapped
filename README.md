# Tax, mapped — CMA Final Paper 15

A static installable web app for the CMA Final Paper 15 syllabus and the four included past question papers.

## Publish with GitHub Pages

GitHub Pages sites are public on the internet, including when the source repository is private on a plan that permits it. On GitHub Free, the Pages repository must be public. Publishing this folder makes all four included question-paper PDFs publicly accessible too. Continue only if that is okay with you.

1. Sign in at [github.com](https://github.com) and create a repository named `cma-tax-mapped`.
2. In File Explorer, open this `outputs` folder and select its contents. On the GitHub repository page, choose **Add file → Upload files**, then drag the selected contents into the upload area. Keep `index.html` at the repository root and preserve the `icons` and `past-papers` folders.
3. Enter a commit message such as `Add CMA tax study app` and commit the upload to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then save.
6. Wait for the Pages deployment to finish. The site address will look like `https://YOUR-USERNAME.github.io/cma-tax-mapped/`.

## Add it to your phone

Open the published HTTPS address in your phone's browser:

- **Android:** Chrome menu **⋮ → Install app** (or **Add to Home screen**).
- **iPhone:** Safari **Share → Add to Home Screen**.

The service worker caches the app and all four PDFs for offline use after the site is opened online. The PDFs together are about 18 MB.
